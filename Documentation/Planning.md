# Планирование проекта CineRate

Документ описывает общий план разработки CineRate по текущей документации проекта.
Формат рассчитан на поэтапную работу: сначала база и backend, затем frontend, интеграция, тестирование и финальная подготовка.

---

## 1. Цель проекта

CineRate - веб-приложение для оценки фильмов и сериалов, похожее на IMDb.
Пользователь может просматривать каталог, искать фильмы, ставить оценки, писать рецензии, вести watchlist и смотреть статистику профиля.
Администратор управляет фильмами, жанрами, персонами и модерирует рецензии.

---

## 2. Основной стек

| Часть | Технологии |
|---|---|
| Backend | ASP.NET Core 10 |
| ORM | Entity Framework Core 10 |
| База данных | PostgreSQL |
| Frontend | React 18 + Vite |
| Состояние | Zustand |
| HTTP-клиент | Axios |
| Стили | Tailwind CSS |
| Авторизация | JWT access token + refresh token |
| Контейнеризация | Docker Compose |

Кеш не используется. Данные читаются и записываются напрямую в PostgreSQL.

---

## 3. Этапы разработки

### Этап 1. Подготовка проекта

Нужно создать структуру решения, настроить backend, frontend, Docker Compose и базовые конфигурации.

Основные задачи:

- создать backend-проекты `API`, `Application`, `Domain`, `Infrastructure`;
- подключить PostgreSQL;
- настроить Entity Framework Core 10;
- создать базовую структуру React + Vite;
- настроить переменные окружения;
- добавить общий `.gitignore`.

### Этап 2. Проектирование и миграции БД

На этом этапе создается структура базы данных по файлу `DatabaseDesign.md`.

Основные задачи:

- создать enum-типы;
- описать сущности `User`, `Movie`, `Rating`, `Review`, `Genre`, `Person`;
- добавить связи многие-ко-многим;
- добавить таблицы сезонов и эпизодов;
- добавить таблицы watchlist, comments, review likes и refresh tokens;
- создать первую миграцию;
- проверить применение миграции к PostgreSQL.

### Этап 3. Авторизация

Нужно реализовать регистрацию, вход, выход, refresh token и OAuth через Google.

Основные задачи:

- регистрация через email;
- хеширование пароля;
- подтверждение email;
- вход по email и паролю;
- выдача access token и refresh token;
- хранение refresh token в БД;
- logout с отзывом refresh token;
- вход через Google OAuth;
- middleware для защиты API.

### Этап 4. Каталог фильмов

Нужно реализовать просмотр каталога, карточки фильмов, страницу фильма и поиск.

Основные задачи:

- CRUD фильмов для администратора;
- публичный список фильмов;
- пагинация;
- сортировка;
- фильтрация по жанру, году, рейтингу и типу контента;
- поиск по названию;
- страница фильма;
- отображение жанров, стран, языков и актерского состава;
- рекомендации похожих фильмов.

### Этап 5. Сериалы, сезоны и эпизоды

Этот этап расширяет каталог для контента типа `Series`.

Основные задачи:

- создать сезоны для сериала;
- создать эпизоды внутри сезона;
- показать сезоны и эпизоды на странице сериала;
- дать пользователю возможность оценивать эпизоды;
- пересчитывать рейтинг эпизода.

### Этап 6. Оценки

Нужно реализовать пользовательские оценки фильмов и пересчет рейтинга.

Основные задачи:

- поставить оценку фильму;
- изменить оценку;
- удалить оценку;
- запретить несколько оценок одного фильма одним пользователем;
- пересчитывать `average_rating` и `ratings_count`;
- показать распределение оценок от 1 до 10;
- автоматически переносить фильм в `Watched` после оценки.

### Этап 7. Рецензии и комментарии

Нужно реализовать пользовательский контент вокруг фильмов.

Основные задачи:

- написать рецензию;
- запретить больше одной рецензии от пользователя на один фильм;
- отправлять новую рецензию на модерацию;
- редактировать и удалять рецензию;
- добавлять комментарии;
- удалять комментарии;
- ставить и снимать лайк рецензии;
- обновлять счетчик лайков.

### Этап 8. Профиль пользователя

Нужно реализовать личный кабинет и пользовательские списки.

Основные задачи:

- страница профиля;
- watchlist;
- список просмотренного;
- статистика пользователя;
- распределение оценок пользователя;
- любимые жанры;
- история рецензий.

### Этап 9. Админ-панель

Нужно реализовать интерфейс управления контентом.

Основные задачи:

- добавление фильма или сериала;
- редактирование фильма;
- мягкое удаление фильма;
- восстановление фильма;
- управление жанрами;
- управление персонами;
- загрузка постеров и фото;
- очередь модерации рецензий;
- одобрение и отклонение рецензий.

### Этап 10. Frontend-интерфейс

Нужно собрать основные страницы и связать их с API.

Основные задачи:

- главная страница;
- каталог;
- страница фильма;
- страница сериала;
- страница персоны;
- login/register;
- профиль;
- watchlist;
- админ-панель;
- toast-уведомления;
- темная и светлая тема.

### Этап 11. Тестирование

Нужно проверить основные сценарии пользователя и администратора.

Основные задачи:

- unit-тесты сервисов;
- тесты пересчета рейтинга;
- тесты авторизации;
- проверка API через Swagger или Postman;
- ручная проверка frontend-сценариев;
- проверка миграций БД;
- проверка ролей и доступа.

### Этап 12. Финальная подготовка

Нужно подготовить проект к сдаче или демонстрации.

Основные задачи:

- обновить документацию;
- проверить Docker Compose;
- проверить запуск backend и frontend;
- добавить seed-данные;
- подготовить демонстрационные аккаунты;
- убрать временный код и лишние файлы.
